# 傑出油漆品牌官網

以真實簡報案例與既有品牌素材製作的響應式靜態網站。

## 網站結構
- `index.html`：首頁、服務、品牌介紹、合作夥伴、FAQ 與聯絡資訊
- `cases.js`：作品分類、文字、照片與合作資料
- `style.css`：桌面與手機版樣式
- `script.js`：作品篩選、案例視窗、手機選單、LINE ID 複製
- `assets/`：從原始簡報取出的真實案場照片及品牌素材（WebP）
- `估價單/`：原有估價單工具，保留原樣

## 本機檢視
使用任一靜態 HTTP 伺服器開啟根目錄，例如 `python3 -m http.server 8000`。

## GitHub Pages
在 repository Settings → Pages 選擇 Deploy from a branch、`main`、`/ (root)`。
